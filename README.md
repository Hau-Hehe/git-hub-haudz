git init to create your own local git on your device
git log to check that your project that you want to push in your own local git is exist or not?
git status to see what you have not pushed into local repo yet and what file you've pushed before
git add "your file name" to add exactly which file you want to push into github
git commit -m "Your note right here" to note that this file or those files were changed what things by you
--Finally--
git branch -M main
git push -u origin main
